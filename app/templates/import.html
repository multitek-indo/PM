Semua baris divalidasi sebelum disimpan. Satu baris bermasalah membatalkan seluruh impor; data lama tidak ditimpa.

Ketentuan impor

  1. Format: .xlsx hingga 5 MiB atau .csv hingga 2 MiB, maksimal 5.000 baris data.
  2. Sheet: otomatis memakai Mesin, atau sheet terlihat pertama. Isi nama sheet jika ingin memilih yang lain.
  3. Identitas: code dan name wajib terisi. Gunakan format Text untuk kode/serial agar nol di depan tidak hilang.
  4. Data biasa: rumus, workbook eksternal, dan macro tidak diimpor. Gunakan Paste Special > Values bila sumber berisi rumus.
  5. Jadwal PM: dibuat terpisah setelah master mesin berhasil masuk.

Delapan header template

code, name, category, manufacturer, model, serial, site, line

Header Indonesia seperti Kode mesin, Nama mesin, Jenis mesin, Merek, Nomor seri, Pabrik, dan Line produksi juga dikenali. Delapan kolom tetap harus lengkap; nilai selain kode/nama boleh kosong.

Format lama .xls dan .xlsm belum didukung. Pilih Save As > Excel Workbook (.xlsx), bukan konversi ke CSV.
