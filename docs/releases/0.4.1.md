# Multitek PM v0.4.1 — Pencarian Sparepart pada Mutasi Stok

Perbaikan antarmuka terbatas pada **Stok sparepart → Barang masuk/keluar**.

- Cari sparepart berdasarkan kode (SKU) atau sebagian nama; mendukung beberapa kata dan huruf besar/kecil.
- Maksimal 40 hasil dropdown ditampilkan sekaligus untuk menghindari scroll panjang; ketik lebih spesifik bila hasil lebih banyak.
- Pilihan tetap dikirim melalui field `part` dan diproses oleh `MovementForm`/`move_stock()` yang sudah ada. Tidak ada perubahan angka stok maupun skema database.
- Form lain (permintaan teknisi, master sparepart, opname) tidak berubah.
- Input pencarian hanya aktif dengan JavaScript; jika JavaScript mati, pilihan asli tetap bisa digunakan.
- Validasi server atas ID sparepart dan izin pengguna tetap berlaku.

## Cara penggunaan

1. Buka **Stok sparepart → Barang masuk / keluar**.
2. Ketik kode atau nama pada **Cari sparepart berdasarkan kode atau nama**, misalnya `001`, `bearing`, atau `pisau gerber`.
3. Pilih hasil yang tepat pada dropdown yang sudah tersaring.
4. Pilih jenis transaksi, masukkan jumlah dan alasan, lalu simpan seperti biasa.

## Deployment

Rilis `v0.4.1` mensyaratkan v0.4.0 aktif dan branch `main` bersih/selaras dengan GitHub. Installer menguji kode sebelum menyimpan backup, tidak memigrasikan database, dan hanya mengganti container web/scheduler PM. Tidak ada auto-deploy dari GitHub.
