# Multitek PM v0.4.3 - bilangan bulat, mutasi Excel/CSV, alur persetujuan, izin mesin

Rilis ini **hanya** menangani empat kebutuhan berikut, tanpa perubahan tema, jadwal maintenance, checklist, foto, dan deployment aplikasi lainnya.

1. Nilai stok, minimum, opname, mutasi, dan permintaan ditampilkan sebagai bilangan bulat; input pecahan baru ditolak. Skema numeric lama dipertahankan. Jika saldo historis pecahan ditemukan, installer berhenti daripada membulatkan diam-diam.
2. Menu **Stok sparepart > Impor Excel / CSV** menerima `kode_sparepart,jenis,jumlah,referensi` (satu header); jenis `masuk/keluar`; maksimal 5.000 baris. Impor atomik, dengan idempotensi isi file SHA256. Bila ada kode salah/stok tidak cukup, tidak ada baris yang diproses.
3. Teknisi meminta -> **Pengelola Stok Sparepart** menyetujui. Admin stok/supervisor meminta -> **Manager Sparepart** menyetujui. Peminta tidak dapat menyetujui sendiri. Manager hanya memperoleh izin persetujuan permintaan admin, bukan akses mutasi stok otomatis.
4. Permission Django grup `maintenance.add_machine`, `maintenance.change_machine`, dan `maintenance.delete_machine` sekarang mengendalikan tombol dan endpoint di halaman Master Mesin. Pengguna non-staff tetap dapat menggunakan form aplikasi sesuai izin; login admin Django tetap memerlukan `is_staff`. Hapus mesin ditolak bila ada jadwal/riwayat terkait.

## Penggunaan impor

- Download template Excel atau CSV pada halaman import mutasi.
- Isi **kode_sparepart**, **jenis**, **jumlah**, dan **referensi**. Gunakan kode yang sudah terdaftar, jumlah bulat, dan jenis `masuk`/`keluar`.
- Simpan CSV UTF-8 atau XLSX. Jika ada baris tidak valid, perbaiki file dan impor ulang.
- Impor yang sukses langsung membuat riwayat mutasi stok dengan nama pelaku.

## Perhatian hak akses

- Untuk akun `sparepart`, ubah izin **Grup > Master Mesin**. Setelah login ulang, menu Master Mesin menampilkan tombol sesuai izin.
- Anda tidak harus mengaktifkan **Status staf** untuk menggunakan form Master Mesin pada aplikasi. Namun membuka `/admin/` Django tetap membutuhkan Status staf.
- Tambahkan anggota yang berwenang ke grup `Manager Sparepart` melalui admin. Tidak ada anggota yang diberikan otomatis.
- Izin langsung pengguna dan izin grup Django berlaku jika akun aktif.

## Migrasi dan pemulihan

Rilis menambah field jalur persetujuan permintaan, metadata batch impor, dan permission manager. Riwayat saldo dan work order tidak ditimpa. Backup source/foto/database dan uji restore dilakukan sebelum migrasi produksi. Rollback source saja tidak menghapus tabel tambahan dan tidak melakukan restore DB otomatis.
