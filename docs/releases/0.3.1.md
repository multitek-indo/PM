# Multitek PM v0.3.1 - Foto sparepart

Rilis penambahan fitur terbatas di work order. Fitur lama tidak dimodifikasi.

- Teknisi yang sedang ditugaskan pada work order **terbuka** dapat mengunggah maksimal 10 foto sparepart rusak/dibutuhkan.
- Nama dan kondisi sparepart wajib; catatan opsional. Format JPG/PNG/WEBP maksimal 6 MB dan 24 megapiksel.
- File dikonversi ke JPEG maksimal 1920 piksel, metadata EXIF/GPS dihapus; file hanya berada di direktori privat.
- Supervisor PM/superuser dan teknisi terkait dapat melihat gambar melalui URL yang memeriksa login serta otorisasi work order.
- Setelah work order dikirim atau disetujui foto yang sudah ada tetap terlihat; upload baru hanya saat status open.
- Tidak mengubah role, checklist, status/alur persetujuan, jadwal, tema, Excel, atau perusahaan.
- Storage foto disimpan di `/opt/multitek-pm/sparepart_uploads/` (mount hanya di web `/var/pm-spareparts`).
- Backup wajib meliputi **database PM dan direktori foto**. Backup lokal belum sama dengan backup offsite.
- Tag Git untuk rilis ini: `v0.3.1`. Tag `v0.3.0` tidak diubah.
- Deploy diperlukan; hanya melakukan commit/tag GitHub tidak otomatis mengganti aplikasi di VPS.

**Catatan:** foto tidak menjadi bukti bahwa mesin sudah aman dioperasikan. Semua tindakan tetap mengikuti SOP dan otorisasi keselamatan.
