# Multitek PM v0.4.2 - Perbaikan pencarian sparepart

## Perubahan

- Pada **Stok sparepart > Barang masuk / keluar**, mengetik kode atau nama menampilkan hasil yang bisa **langsung diklik**.
- Klik satu hasil atau tekan Enter pada hasil tunggal untuk memilihnya. Nama pilihan terlihat pada konfirmasi **Terpilih**.
- Sistem mengisi field asli `part` (ID sparepart) sehingga validasi Django, pencatatan mutasi, dan nilai stok tetap sama.
- Mengetik ulang membersihkan pilihan lama agar tidak terjadi pengeluaran barang yang salah.
- Tanpa JavaScript, dropdown bawaan tetap bisa digunakan.
- Perbaikan validasi browser: setelah JavaScript aktif, field pencarian yang terlihat menjadi sasaran pesan wajib diisi.
- Versi aplikasi naik dari 0.4.1 ke 0.4.2.

## Batas perubahan

Tidak ada modifikasi pada model, migrasi, database, logika stok, approval, foto, master mesin, scheduler, admin, identitas perusahaan, konfigurasi Docker, dan dependency.

## Pengujian

- Periksa hasil pencarian berdasarkan kode dan nama dengan dataset besar; pilih item menggunakan mouse, sentuhan, dan keyboard.
- Pastikan `FormData(form).get('part')` sama dengan ID yang dipilih, bukan teks pencarian.
- Uji pencarian tanpa memilih: simpan harus diblokir pada browser, dan validasi server tetap wajib.
- Uji stok masuk/keluar, hak akses, dan fungsi PM lama melalui Django test suite sebelum deploy.

## Deployment

Rilis hanya dari baseline v0.4.1. Backup dan uji restore sebelum mengganti web dan scheduler PM. Tag immutable: `v0.4.2`.
